## About

Welcome to the CinoTech Website repository. This project is built with React, TypeScript, and Vite.

## Development

To get started with the project locally, follow these instructions.

### Prerequisites

- Node.js (Latest LTS recommended)
- npm

### Installation

1.  Clone the repository:

    ```bash
    git clone https://github.com/ngoclinhXD/AzuWeb.git
    ```

2.  Navigate to the project directory:

    ```bash
    cd AzuWeb
    ```

3.  Install dependencies:

    ```bash
    npm install
    ```

4.  Start the development server:
    ```bash
    npm run dev
    ```
